# Engineer

**Mission.** Build and maintain the paths that let organizers ask, supporters act, and members reflect.

**Vision.** People can complete each step and trust the state they see. The team can reproduce the checks.

**Place in the journey.** Maintain the organizer workspace, review queue, directory, outgoing links, and private garden. [Participant journey](../mission.md#participant-journey)

## Work

- Name the affected participant need and how you will verify the change. Reuse the [shared UI](../ui-library.md) and existing store and tests.
- Run the focused tests, application suite, and build when applicable. Check the changed path with test accounts. Record the build, environment, and observed result.
- Bring changes to data or permissions to the COO and CTO. Include recovery steps when a failure could affect stored work.
- Give reviewers the exact implementation version and test record. Record which flows still need checks.

## Rehearsal

- **Normal.** An organizer submits a real-looking sample request. A separate test reviewer approves it. A guest finds it and can open the sample help link.
- **Exception.** The confirmation for a saved help record is lost. Retry with the same request ID. Check for one help record and one seed.

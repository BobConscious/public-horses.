# Public Horses

Public Horses helps people find concrete ways to support projects that serve their communities. The experience is called **Kshetra**. Anyone can support a project, organize one, or do both.

## First pilot

Start with **Nourishment** and up to three current food pantry requests. Each listing shows what the pantry needs, when it needs it, and where to give directly. Confirm the request and giving link with the pantry before listing it.

After helping, a supporter can add a private seed to a watercolor garden on their device. Each seed represents an act the supporter chose to remember.

## Fast for Hunger

Fast for Hunger is the proposed first pilot partner. It can introduce Kshetra at the end of a meditation or after a kindness report. Fast for Hunger owns its registration, reports, and globe. Public Horses owns its listings and garden.

## What to check

- A guest can find a current need and reach the pantry's official giving page.
- Expired or unverified requests stay out of the directory.
- A supporter can add a seed, return to the garden on the same device, and keep that reflection private.
- After two new-moon cycles, check whether partners update their requests and supporters return to find new ways to help.

Later, let organizers submit requests for review. Add more fields and accounts when the pilot shows people would use them. Keep any shared database records under separate access rules for Public Horses.
